# CrossBeam local review extension

Preserve Mike Brown's original MIT-licensed CrossBeam and distinguish this extension from the original AI/cloud system.

- All new demo files are fictional. Never publish imported user plans or addresses.
- Exact page quotes establish text provenance, not legal compliance or visual plan correctness.
- Scanned/blank extraction is explicit; do not claim OCR, blueprint vision, signatures, dimensions, or current code interpretation.
- Reviewed items require a response, checked evidence, and explicit human confirmation. Exports remain drafts for professional review.
- Use official source links with verification dates; do not hardcode changing numeric legal requirements.
- Keep everything local without paid calls. Validate project/document identity on all reads and writes.
- Run local_review tests and JS syntax checks, visually inspect generated demo PDFs, then push lowercase feature commits.
