# Local review scope

Extend the public MIT CrossBeam repository with a low-cost local correction-review workflow: immutable PDF/text imports, editable candidate correction extraction, page-level quote evidence, review notes and questions, a human-reviewed pre-submission task checklist, audit trail, source links, and draft Markdown/PDF/JSON response packages.

Original CrossBeam by Mike Brown: https://github.com/mikeOnBreeze/cc-crossbeam. Original AI/cloud architecture and capabilities remain available under UPSTREAM_README.md, but no cloud account, paid model run, or production city pilot is claimed for this extension.

Deliver a loopback Python/SQLite app with a plain browser UI, fictional demo, source attribution, automated tests, portfolio docs/figures, separate Desktop checkout, and pushed GitHub fork. No automated permit approval, legal interpretation, engineering certification, OCR/vision, cloud deployment, or real-document publication.
